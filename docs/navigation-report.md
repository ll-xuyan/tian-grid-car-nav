# 田字格小车 · 自主导航（方案B：Pure Pursuit）交付说明

> 完成：2026-10-12 11:20 · 接续 zcode 的方案设计，由 WorkBuddy 实现并实测通过
> 对应需求：① 车道正中心循迹 ② 用户选定起点/终点 ③ 设定速度

---

## 一、交付内容一览

| 文件 | 说明 |
|---|---|
| `pure_pursuit_nav.py` | 导航节点（约 460 行，全中文注释） |
| `nav_view.rviz` | RViz 导航界面（俯视图 + 规划路径 + 选点工具） |
| `nav_pp.launch.py` | 一键启动导航 + RViz 的 launch 文件 |
| `start_pp_nav.sh` | 用户启动脚本（检查仿真后启动导航） |
| `pp_point.sh` | 命令行选点脚本（不用 RViz 时） |
| `操作手册.md` | 已新增"自主导航"章节（VM 与共享目录同步更新） |

**导航节点核心设计**：

1. **车道居中（双保险）**
   - 路径直接取在 1.5m 走廊的**正中心线**上（田字 "#" 网格，Dijkstra 路由 + 拐角切角）
   - 行驶中 **Pure Pursuit 前视追踪 + PID 横向纠偏**，20Hz 闭环修正
2. **选起点/终点**：RViz 里 `2D Pose Estimate`（起点）+ `2D Goal Pose`（终点）；
   起点也可作为"途经点"（小车先开到起点再去终点）；另支持命令行参数模式
3. **设定速度**：`speed` 参数，运行中可 `ros2 param set` 实时调整；
   另有 `regulated` 弯道自动减速开关（已验证）
4. **可靠性**：目标在身后（掉头）时先**原地转向**再行驶；雷达安全保护
   （前方 0.2m 停车 / 0.5m 减速）；点选坐标自动吸附到车道中线
5. **可追溯**：每次任务轨迹自动记录到 `~/pp_log/`（CSV，含横向误差列）

## 二、实测结果（虚拟机仿真，6 次任务全部成功到达）

| # | 场景 | 结果 | 用时 | 最大横向误差* |
|---|---|---|---|---|
| ① | (0,0)→(4.25,4.25)（含直角弯） | ✅ 到达 | 35s | **0.093 m** |
| ② | 长路线 17.9m（旧版掉头画弧测试） | ✅ 到达 | 74s | 0.440 m（掉头暂态） |
| ③ | 掉头起步 + 直线 8.5m | ✅ 到达 | 37s | 0.235 m（掉头暂态） |
| ④ | 指定起点作途经点（2 个直角弯） | ✅ 到达 | 53s | **0.094 m** |
| ⑤ | 实时调速 0.25→0.40 m/s | ✅ 到达 | 26s | 0.240 m（掉头暂态） |
| ⑥ | 弯道自动减速 regulated | ✅ 到达 | 37s | 0.197 m |

\* 横向误差 = 小车到车道中线的距离；走廊半宽 0.75m。
**常规行驶（直道+弯道）误差 ≤ 9.4cm**；最大误差只出现在掉头起步瞬间，3 秒内收敛回中线。

- "原地转向"改进：② 的 0.44m 掉头大弧问题在③之后版本已修复（先原地对准再行驶）
- 实时调速验证：0.25→0.40 后日志即刻生效；弯道减速验证：转弯时 0.40→0.24→回升
- 测试中发现并修复 1 个隐蔽 bug：Dijkstra 等距平局时堆比较字符串/元组报 TypeError

## 三、在虚拟机里怎么用（2 个终端）

```bash
# 终端 1：启动仿真
~/start_car.sh

# 终端 2：启动导航 + RViz 导航界面
~/start_pp_nav.sh

# 然后在 RViz 里：
#   1) [2D Pose Estimate] 点小车当前位置（选起点，可选）
#   2) [2D Goal Pose]    点终点 → 小车自动出发，到点停车
```

调速：`ros2 param set /pure_pursuit_nav speed 0.40`
命令行选点（不用 RViz）：`~/pp_point.sh goal 4.25 4.25`
